## Website 2: https://developer.mozilla.org
- Navigation menu: It is wrapped in <nav> tag. I saw <nav class="main-nav"> at the top inside <header>. Inside nav there is ul and li for links.
- Search bar: It is inside <form role="search">. Structure is form > input type="search" with placeholder "Search" + button with search icon. The input has name="q".
- Hover effect: I long-pressed links and checked Styles panel. On hover a:hover it becomes underline and blue color #0069c2. Top menu links get light grey background when hover.

## Website 3: I chose https://en.wikipedia.org
- 5 elements I found:
    1. <header> - top header with logo
    2. <nav> - left side menu
    3. <main> - main content area
    4. <footer> - bottom footer
    5. <a> - links inside article
- Form: I found search form at top: <form id="searchform">. Inputs are: input type="search" name="search", hidden input, and button type="submit" Search.
